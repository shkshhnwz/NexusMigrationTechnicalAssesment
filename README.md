## Project Overview

This project focuses on recreating the primary user interface and user experience of the Nexus Migration website with responsive design and reusable React components.

The goal was to build a clean and visually accurate frontend implementation within a limited timeline while maintaining responsiveness and component-based architecture.

---

## Features

- Responsive Navbar
- Hero Section with CTA
- Visa Services Cards
- Reusable UI Components
- Mobile Responsive Layout
- Modern UI Design
- Hover Effects & Interactive Elements
- Clean Component Structure
